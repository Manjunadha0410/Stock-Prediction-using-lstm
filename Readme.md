# Stock Prediction using LSTM

This project demonstrates how to predict stock prices using Long Short-Term Memory (LSTM) recurrent neural networks. The model is trained on historical stock data to forecast future prices based on past patterns.

## features
- LSTM model for time series prediction 
- Hyperparameter optimization using Optuna with TPE sampler
- Early stopping and learning rate reduction callbacks
- Median pruning for efficient hyperparameter search

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Manjunadha0410/Stock-Prediction-using-lstm.git
   cd Stock-Prediction-using-lstm
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the Jupyter notebook:
   ```bash
   jupyter notebook Stock-Prediction-using-lstm.ipynb
   ```
